# Character Specification · 五条悟

- `gojo` / `gojo-v1`；只替换 3D 外观，同场可出现两个五条悟及通用人形。白色尖发、眼罩、高领衣摆和青色指印用于默认俯视识别；识别率尚无人工结果。
- [程序化源](../../../../client/src/battle3d/characters/gojo.ts) 由项目内手写；既有 WebP 提供参考及 UI 展示。未引入新外部模型、贴图、clip 或加载依赖；不声称拥有额外 IP 许可。
- +Y 上 / +Z 前，脚底 y=0，局部刚性关节；站姿头高供名牌。实例 13 网格、3,894 三角面、2 材质、约 410.7 KiB 几何数组；同角色不同 PID 隔离，其他 ID 保留通用 rig。
- 五个必需动作：待机 `idle`，近战出手 `attackSwing`，普通受击 `flinch`，余命 `reviveRise`，最终淘汰 `dead`。实战与日志见 [报告](../../../../docs/V5.0-B.md)。场景拥有朝向/位移和时钟，死亡/起身不被迟到普通动作抢占，角色不能更改 HP、余命、房间或胜负。
- 非目标：GLB、骨骼与外部动画、专属领域动作、第二角色、规则、2D、发布。真机与盲测待补，不自动开启下一阶段。
