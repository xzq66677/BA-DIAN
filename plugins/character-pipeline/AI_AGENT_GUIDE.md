# AI Agent 接单指南

## 十步协议

1. 读本目录 `README.md`，确认版本、适用路线与证据标签。
2. 读本指南，确认工作区和角色边界。
3. 读对应阶段规范及规范指定的代码/证据入口；无需把整套规范都读一遍。
4. 读填写后的 [任务书](templates/character-task.md)，确认输入、可写路径、验收与输出。
5. 运行 `git status --short`、`git rev-parse --short HEAD`；记录未提交内容，隔离副本包含所需未提交源。
6. 核对边界和单一文件所有者；任务与现有修改冲突、证据或授权缺失时，记录阻塞并交主 Agent，不私自提升权限。
7. 只执行分配的工作，保留原证据和失败现场。
8. 运行指定验证，区分 VERIFIED / UNVERIFIED / DEPRECATED；产物只落允许路径。
9. 记录改动、命令、环境、通过数及尚未覆盖情况；重复或卡点也记录。
10. 回传 [交付报告](templates/character-report.md) 的适用字段，等待主 Agent 合并结论。“提交报告”不是 Git commit。

允许：查素材、检查格式/大小/命名、角色级配置与动作映射、受限接入、测试、截图、报告、文档。禁止：推翻架构或 V4.3、改规则/数值/伤害/胜负/事件顺序、重写引擎与 2D、同时改多角色、擅改规范、引入未经审查的资源、清理已有改动、提交/推送/部署。源授权不明、共享接口冲突、需求需要改玩法或需要生产写权限时直接交主 Agent；可继续独立的非阻塞核验。
