# 视觉 QA

1. 锁定角色、PID、设备/浏览器、DPR、视口、种子、房间、镜头、演出速度。桌面照默认机位与同房密集视角；桌面窄屏和真机分列。留旧实现基线，动作证据不得靠放大掩盖默认机位问题。
2. 每个必需动作保存真实画布原始帧，记录 pose、进度和同一 PID 对应的权威日志 seq/回合与快照。待机取稳定机位；还留桌面与窄屏整页，核对脚底、边界、选择与 HUD。为阅读可额外裁同一尺寸比例的图版，不能替代原图。
3. 脚不漂不穿、动作轮廓有区别、登场/离场与存活一致、模型及 UI 不妨碍选取。查看默认比例的原图，遮名牌盲测能否说出两项识别特征并区分受击、复活、淘汰；建议至少两名实际观察者并记录结果。真机横竖屏、密集房间、真实触控、活跃帧时与长局单独验收。
4. 发现问题要记录原帧/步骤/实际与预期、改动、相同条件复测。至少一次有失败证据的视觉迭代；无法人工看图就明确 UNVERIFIED，不能用“代码跑了”签视觉门槛。投影包围框不是真实遮挡：`meshBitmap` 是画布位图边界，`meshCss` 是画布 CSS 位置，`canvasRect` 是视口位置，`overlaps` 是矩形交集比例；投影中心不等于点击范围。

归档复核与人工签收分开。复核者可独立核验 PNG 解码、尺寸/非空像素、探针、同局同 PID/回合与日志；不能收到图像时仍可交付这些结果，将目视签收留为 UNVERIFIED。回合关联不等于帧与 seq 直接绑定；归档缺少该绑定时写明关联依据，不能声称精确同步。
