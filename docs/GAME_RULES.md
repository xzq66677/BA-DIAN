# 拔典 · 游戏规则文档

> 本文档区分三类内容：**正式规则**（任务书明确 + 用户确认）、**规则假设**（资料未明确，开发时采用可配置决策并记录）、**待确认项**（OCR 缺失/存疑，未擅自补全）。

## 一、正式规则

### 1. 基础
- 玩家至少 2 人，无硬性上限（受资源限制，UI 层限制 20 人）。
- 每名玩家初始生命值 3（角色可覆盖）。HP 降至 0 立即淘汰。
- 每名玩家拥有固定初始房间（R1…Rn）；初始房间主人被淘汰后房间仍然存在；可返回自己的初始房间；可反复进入同一房间；一个房间允许多人同时存在；玩家死亡后立即移出房间成员集合（成员由存活玩家实际位置动态决定）。

### 2. 回合流程
1. **初次判定（行动资格）**：所有存活玩家参与，**隐藏出拳**（全部提交前服务端不向任何客户端暴露拳种与日志）。服务端统一判定：
   - 石头胜剪刀、剪刀胜布、布胜石头；
   - 恰好两组出拳 → 胜组全体获得资格，败组无资格（多名胜者均保留）；
   - 全员同拳（平局）或三拳齐全（三人循环）→ 全员重新判定，**不得随机决定胜者**；
   - 淘汰玩家不参与判定；非法出拳与重复提交被拒绝且不修改状态。
2. **二次判定（行动排序）**：仅资格者参与，输者优先行动、赢者靠后；同输者/同赢者递归判定；三人循环/同拳重判；直到确定完整顺序；**不剥夺任何人的行动资格**。
   - 实现说明：本版二次判定由服务端以对局种子代掷出拳（`secondJudgeMode: 'serverRoll'`），保证确定性、可复现并简化交互；玩家手动出拳模式留有配置位（见已知问题）。
3. **行动阶段**：资格者按队列依次执行**一次**行动；行动期间被淘汰者跳过；非法行动拒绝执行且不消耗行动次数；重复提交被拒绝。
4. **回合末**：延迟事件结算（大伊万爆炸等，动态判定结算时状态）。
5. 只剩一名存活玩家 → 游戏结束，显示胜者/最终状态/日志；禁止继续提交；支持重开。全员同灭 → 平局。

### 3. 行动（基础）
| 行动 | 规则 |
|---|---|
| 移动 | 移动到任意玩家的初始房间，无距离限制；移动后现身（离开躲藏）【假设，见下】 |
| 攻击 | 默认**近战**：目标须在同房间，默认伤害 1，不允许攻击自己；远程攻击需角色具备能力 |
| 回复 | 回复至满血；满血时仍可回复（合法但无变化）；无次数限制（每回合一次行动） |
| 躲藏 | 进入躲藏：指向性攻击无法锁定；AOE 与无视躲避攻击仍可命中；移动/攻击后现身 |
| 找出来 | 找出同房间躲藏的玩家（使其现身） |
| 跳过 | 无效果 |
| 瞄准 | 远程需瞄准角色（吹箫哥/五条悟）锁定目标；攻击后瞄准消耗 |

伤害由服务端统一计算。伤害管线顺序：**转移阶段**（大贱客吸引）→ **躲避判定**（躲藏/隐身拦截指向性伤害）→ **防御阶段**（马保国太极反弹）→ 结算（秒杀/扣血/附加效果）→ 淘汰。

### 4. 角色机制（正式规则，来源：原始角色资料 + 用户确认）

**拔棍**：需先「拔棍」才能造成伤害（拔棍消耗一次行动）；拔棍状态下攻击**无视躲避（含隐身、躲藏）**；收棍后恢复。

**吹箫哥**：仅能远程攻击（异房间），需先「瞄准吹箫」锁定目标；无法近战。伤害 1。

**五条悟**：血量 3；近战 3 伤；远程 2 伤需瞄准；**领域展开**（消耗行动）后：远程免瞄准、判定平局算五条悟胜；存在**领域对冲**（多名领域持有者时平局效果互相抵消）。

**老大爷**：血量 3；近战 3 伤远程 2 伤；领域展开后平局算老大爷赢；强化后近战 5 伤远程 3 伤；与五条悟领域对冲。

**马保国**：血量 4 攻击 1。
- 混元形意太极：除大伊万爆、肉山坐（实现为 `noReflect` 标记的伤害）外，受到伤害时进行判定（服务端种子代掷，可选触发），赢则**原伤反弹**给来源；反弹伤害带 `reflected` 标记，**不再触发反弹判定（反弹链终止）**。
- 闪电五连鞭：对同房间敌人进行 5 场判定（种子代掷），按胜次造成其最大血量 20/40/60/80/100% 的伤害（单次伤害事件）。
- 不讲武德：被击杀后与击杀者进行 5 局判定（种子代掷），赢 ≥3 局则击杀者同时死亡；由不讲武德造成的死亡不再触发。

**伍六七（五六七）**：血量 3；攻击为 **3 段 AOE**：每段对**攻击发动时角色所在房间**内所有玩家（默认不含自己，可配置 `hitSelf`）造成 1 伤；释放房间固定为攻击时所在房间；目标集合为攻击时房间成员快照；**每段独立结算**（段间死亡不再受击、反弹/护盾每段独立触发）。

**卖大伊万的小女孩**：血量 3；可向任意房间（含自己所在房间）投掷大伊万；爆炸时间为**所有玩家结束行动后**（本实现默认 `ivanExplodeTiming: 'sameRoundEnd'`，即投掷回合所有人行动结束后；`nextRoundEnd` 模式为下一回合末，可配置）；爆炸时**动态判定目标房间成员**（不使用投掷时快照），对房间内所有玩家造成秒杀（`noReflect`，不触发太极反弹）。

**今日勇者**：血量 3 攻击 2。原稿技能正文缺失（OCR），**不编造技能**；作为游戏通用随机模块测试代表。

**大贱客**：血量 3。
- 被动「吸引全场伤害」：在场存活时，指向其他玩家的**非精神伤害**（含 AOE 伤害与延迟伤害）自动转移至大贱客；**仅转移伤害数值**，不转移附加效果/状态/控制；精神伤害不转移；已转移伤害不重复转移。
- 攻击为辱骂（精神攻击）：对同房间目标累计辱骂次数，**3 次致死**（精神致死），致死后计数重置；辱骂无视躲避（对抗性敌人设定，见假设）。

**大屁孩**：判定历史（每次判定子轮记录 赢/平/输）**跨回合记忆**：
- 连续三项出现**三种不同**结果（赢平输任意排列）→ **暴走**：随机一名其他玩家受到精神攻击（伤害默认 1，可配置 `berserkDamage`）；触发后历史清零。
- 连续三项**相同**（赢赢赢/平平平/输输输）→ **自爆**（自身立即淘汰）；触发后历史清零。

**无业游民（默认角色）**：无被动。

## 二、规则假设（已实现，可在配置调整，待用户确认）

| 编号 | 假设 | 理由 |
|---|---|---|
| A-01 | 移动后现身（离开躲藏）；攻击后现身 | 原稿未明说；躲藏需有代价否则无解 |
| A-02 | 二次判定出拳由服务端种子代掷 | 原稿未明确第二判定是否玩家手出；代掷保证可复现与流畅体验 |
| A-03 | 技能内判定（五连鞭/不讲武德/太极/暴走目标选择）由服务端种子代掷 | 原稿未明确；可复现 |
| A-04 | 大伊万爆炸默认本回合所有人行动结束后（`sameRoundEnd`）；卡片文本「下一个分出胜负回合末」实现为 `nextRoundEnd` 配置项 | 任务书 20.6「爆炸时间为所有玩家结束行动后」+ 用户确认 34 条；两种时机均已实现 |
| A-05 | 伍六七 AOE 默认不含自己（`hitSelf` 可开） | 原稿「对所有玩家」未明确是否含自身 |
| A-06 | 辱骂需与目标同房间、无视躲避 | 原稿「对抗性敌人无视躲避」语义不明，按正面冲突理解 |
| A-07 | 大屁孩暴走伤害默认 1（可配置）、目标随机（种子） | 原稿未给数值与目标规则 |
| A-08 | 大屁孩自爆=自身淘汰（不伤及房间他人） | 原稿未明确范围；参照废人弱/小恶魂的自爆均有明确范围，大屁孩未写 |
| A-09 | 判定历史记录粒度=每次判定子轮（初次判定的平局重判子轮、二次判定子轮均记录） | 大屁孩需要 赢/平/输 三值；分组判定最终结果只有赢/输，平局产生于重判子轮 |
| A-10 | 领域对冲=平局算胜效果互相抵消（平局保持平局） | 原稿「存在领域对冲」未给细节 |
| A-11 | 五条悟领域为持续生效（不设过期） | 原稿未给持续时间 |
| A-12 | 玩家提交出拳的「已提交」状态公开（拳种保密） | 物理版可见举手动作；只暴露状态不暴露选择 |
| A-13 | 出拳/行动超时由服务端代掷/跳过（30s/45s，可配置） | 防止离线玩家阻塞对局 |
| A-14 | 淘汰玩家的延迟效果不再结算（对死者的伤害无效） | 常规处理 |
| A-15 | 转移伤害优先于太极反弹判定（大贱客在场时马保国受到的伤害先被吸引） | 「自动吸引全场伤害」为持续被动；两者同场时的先后原稿未定 |
