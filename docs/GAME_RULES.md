# 拔典 · 游戏规则文档

> 本文档区分三类内容：**正式规则**（任务书明确 + 用户确认）、**规则假设**（资料未明确，开发时采用可配置决策并记录）、**待确认项**（OCR 缺失/存疑，未擅自补全）。

## 一、正式规则

### 1. 基础
- 玩家至少 2 人，无硬性上限（受资源限制，UI 层限制 20 人）。
- 每名玩家初始生命值 3（角色可覆盖）。HP 降至 0 立即淘汰。
- 每名玩家拥有固定初始房间（R1…Rn）；初始房间主人被淘汰后房间仍然存在；可返回自己的初始房间；可反复进入同一房间；一个房间允许多人同时存在；玩家死亡后立即移出房间成员集合（成员由存活玩家实际位置动态决定）。

### 2. 回合流程
1. **初次判定（行动资格）**：所有存活玩家参与，**隐藏出拳**（全部提交前服务端不向任何客户端暴露拳种与日志）。服务端统一判定：
   - 石头胜剪刀、剪刀胜布、布胜石头；
   - 恰好两组出拳 → 胜组全体获得资格，败组无资格（多名胜者均保留）；
   - 全员同拳（平局）或三拳齐全（三人循环）→ **算一个独立的平局回合**：本回合无人获得行动资格、照常回合末结算并翻页，下一回合重新进行一轮完整的回合判定，**不得随机决定胜者**（2026-11-21 修订：原实现为同回合内重判子轮，现按规则本意改为平局消耗回合——按回合计数的角色机制依赖此语义）；**例外：场上存在生效领域时，领域持有者可在该平局回合行动，但平局结果不变（2026-11-24）**；
   - 淘汰玩家不参与判定；非法出拳与重复提交被拒绝且不修改状态。
   - **出拳揭示（2026-11-20）**：回合判定结算完成后，出拳结果对本局**所有人公开**——中央「出拳揭示」台按座次展示每人的拳种（✊/✌️/✋）与胜/平/负、判定结论，同时显示在每人卡面角标、座位标记与战斗日志里，所有人随时能看到彼此出了什么；而**提交阶段**（含平局回合翻页后的新一回合）服务端快照只下发「谁已提交」，不含任何拳种（`reveal: null`），因此全员可见并不破坏隐藏出拳的公平性。平局回合翻页后揭示台仍保留显示上一轮（平局回合）的出拳。
2. **二次判定（行动排序）**：仅资格者参与、**亲自出拳**（隐藏提交，逐子轮递归）；输者优先行动、赢者靠后；同输者/同赢者递归判定；三人循环/同拳重判；直到确定完整顺序；**不剥夺任何人的行动资格**。（注意级别：二次判定是**行动排序**，与回合判定的平局翻页是两回事——排序内部的循环/平局在同一轮排序里递归重判，不消耗回合。）
   - 实现说明（**2026-11-21 改造**）：二次判定改为**资格者亲自出拳**（`secondJudgeMode: 'player'`，线上房间默认）。每完成一个子轮即揭示该子轮拳种并结算；进入下一层（输组/赢组）时再次等待该组出拳，直到顺序完整。AI 由服务端即时代出（走同一 `submitOrderThrow` 接口），房间内 ≥2 名真人时按 30s 超时代掷（与初次判定共用配置、同样只在「有人等」时布防）。`serverRoll`（种子代掷）保留为引擎选项，仅供自动化用例 / 机制测试场使用。
   - **领域不参与二次判定**（2026-11-21）：即使领域持有者在场，排序子轮的同拳平局也只是平局并同组重掷，不注入领域效果。
   - **角色判定历史不记录二次判定**（2026-11-21）：判定历史只由回合判定（rps1）写入，因此大屁孩的暴走攻击与自爆判定与二次判定完全无关。
   - 顺序来源（2026-11-20 明确）：行动顺序**完全由二次判定的胜负结果决定**——每一层「输者整组排在前、赢者整组排在后」，同侧继续递归判定；每层判定都写入日志，因此顺序可追溯。仅一名玩家获得资格时跳过排序直接行动（不额外出拳）。
3. **行动阶段**：资格者按队列依次执行**一次**行动；行动期间被淘汰者跳过；非法行动拒绝执行且不消耗行动次数；重复提交被拒绝。
   - **技能内判定（`judge` 阶段，2026-11-22，Issue #10）**：马保国「混元形意太极 / 闪电五连鞭 / 不讲武德」在行动或死亡流程中触发时，对局**暂停**进入 `judge` 阶段——**双方（马保国 vs 对手）各自隐藏出拳**，逐局揭牌结算；AI 由服务端即刻代出，房间内 ≥2 名真人时按出拳超时代掷。
     - 太极是反应型（出现在别人的行动里）：本次伤害**先挂起**，判定结束后再按结果补结算（反弹或正常受伤），不打断当前行动的其它结算。
     - 五连鞭 / 不讲武德在判定全部结束后才落地伤害，随后继续推进行动队列；回合末引爆的大伊万炸死马保国时同理（判定在回合末收尾前完成）。
     - 提交阶段快照只下发「谁已出拳」，不含拳种；每局结算后拳种公开写入战斗日志。
4. **回合末**：延迟事件结算（大伊万爆炸等，动态判定结算时状态）；平局回合同样进行回合末结算，但**大伊万只在分出胜负的回合末引爆**（平局回合顺延）。**炸弹先结算、后做胜利判断**：存在已激活的大伊万时，行动/判定阶段不提前终局，回合末把炸弹炸完才判胜负（最后一名存活者在爆炸房间内则同归于尽平局）。
5. 只剩一名存活玩家 → 游戏结束，显示胜者/最终状态/日志；禁止继续提交；支持重开。全员同灭 → 平局。

### 3. 行动（基础）
| 行动 | 规则 |
|---|---|
| 移动 | 移动到任意玩家的初始房间，无距离限制；移动后现身（离开躲藏）【假设，见下】 |
| 攻击 | 默认**近战**：目标须在同房间，默认伤害 1，不允许攻击自己。远程攻击需角色具备能力；**远程默认无需瞄准**，仅显式声明 `rangedNeedsAim` 的角色需要瞄准，并在其卡面/描述中注明。当前仅五条悟默认需要瞄准，领域展开后免瞄准；吹箫哥、老大爷等远程角色默认免瞄准——用户确认（2026-11-20）。**远程攻击只能指向异房间目标；同房间目标必须走「近战」校验**（2026-11-24 修复，Issue #65：此前引擎未校验房间，同房间传 `ranged:true` 也能打出远程伤害，吹箫哥因此可绕过「无法近战」、五条悟可把 1 伤近战换成 2 伤远程；现在违规请求被拒绝且不消耗行动） |
| 回复 | 回复至满血；满血时仍可回复（合法但无变化）；无次数限制（每回合一次行动） |
| 躲藏 | 进入躲藏：指向性攻击无法锁定；AOE 与无视躲避攻击仍可命中；移动/攻击后现身 |
| 找出来 | 找出同房间躲藏的玩家（使其现身） |
| 跳过 | 无效果 |
| 喝牛奶 | 嘲讽性质，无实际作用（用户确认） |
| 瞄准 | 仅需瞄准的角色（五条悟）可用；锁定一名目标，远程攻击后消耗（吹箫哥无需瞄准） |

伤害由服务端统一计算。伤害管线顺序：**转移阶段**（大贱客吸引）→ **躲避判定**（躲藏/隐身拦截指向性伤害）→ **防御阶段**（马保国太极）→ 结算（扣血/附加效果）→ 淘汰。其中太极在 player 模式下只把伤害**挂起**（防御钩子返回待处理判定 `deferTo`）：本次扣血跳过，等双方出拳判定结束后由角色回调补结算（可能改打攻击者）。

### 4. 角色机制（正式规则，来源：原始角色资料 + 用户确认）

**拔棍**：需先「拔棍」才能造成伤害（拔棍消耗一次行动）；拔棍状态下攻击**无视躲避（含隐身、躲藏）**；收棍后恢复。

**吹箫哥**：仅能远程攻击（异房间），**无需瞄准，直接选择目标远程攻击**（用户确认 2026-11-20）；无法近战。伤害 1。

**五条悟**：血量 3、**2 条命**（首次致死消耗一条命并满血复活，第二次致死才淘汰；用户确认 2026-11-20）；**近战 1 伤（2026-11-24 用户确认：始终为 1，领域内也不加成）**；远程 2 伤需瞄准；**领域展开（无量空处）**（消耗行动）后：远程免瞄准、**判定平局时可在该平局回合行动（平局结果不变）**。领域为**全场唯一场地状态**（用户确认 2026-11-20 修订，见 4.1）。

> 2026-11-24 修订（作者确认）：
> - 近战伤害由 3 改为 **1**（`meleeDamage: 1`），远程仍 2 伤。
> - 「平局」口径包含**三种不同出拳的三人循环**，不再只算全员同拳。
> - **领域不把平局改判为胜**：持有者只是获得「平局回合的行动资格」（判定结果仍是平局，大伊万照样顺延、大屁孩照样记平）。
> - 「无量」就是**领域展开**本身，不新增独立技能。
> - 领域被覆盖后**可以再次展开夺回**（后展开者生效）。

**老大爷**：血量 3；近战 3 伤远程 2 伤；领域展开后平局回合可行动（平局结果不变）；强化后近战 5 伤远程 3 伤；与五条悟同属领域体系。

#### 4.1 领域规则（2026-11-20 修订，2026-11-24 明确「平局行动」与再展开）

- **全场唯一**：同一时刻只有一个领域生效。展开领域时若他人持有领域，则**后展开者覆盖先展开者**，原持有者的领域立即失效（日志记录「领域覆盖」）。
- **被覆盖后可再展开**：原持有者 `domain` 已失效，再次使用「领域展开」即反向覆盖当前持有者（2026-11-24 作者确认；仅"自己正持有"时重复展开会被拒绝）。
- **平局回合行动**：判定子轮为「全员同拳」**或「三拳齐全（三人循环）」**时（2026-11-24 修订：三人循环同样属于平局），若存在生效的领域持有者，则该回合仍是**平局**，但持有者获得该回合的**行动资格**（`tieAct`，行动完照常回合末结算翻页）。不重判、不判胜。
- **不改判的后果**：判定历史与战绩仍记**平**（大屁孩只按自己的输赢/平局累计）；大伊万仍然只在**分出胜负**的回合末引爆，平局回合（含领域平局行动）顺延。
- **不触发的情形**：两组出拳有明确胜负时领域不介入；领域持有者不在本子轮（已退场/领域失效）时不触发。
- **不参与二次判定**：排序子轮同拳/循环仍是平局并同组重掷，不注入领域效果。
- **持续性**：领域一旦生成即持续保留，**不因回合推进、判定重来（平局重判）、普通胜负或进入行动阶段被清除**；也不因消耗命数复活而消失。
- **失效条件**：仅两种——① 被其他领域覆盖；② 持有者退场（淘汰/踢出/主动退出）。
- 原先的「领域对冲（多领域互相抵消）」已被覆盖机制取代：不再出现多人领域并存互相抵消、导致平局永远无法行动的状态。

#### 4.2 精神攻击（独立词条，2026-11-24 作者确认）

精神攻击**不是普通攻击的一种伤害数值**，而是一类**独立结算**（引擎唯一入口 `shared/src/mental.ts` 的 `mentalKill()`）：

- **秒杀**：伤害 = 目标**当前血量**，走普通扣血管线（复用伤害事件、战绩与淘汰链），一击必杀。
- **无视躲藏/隐身**：躲起来也躲不掉（`bypassHide`）。
- **无视命数**：五条悟式「消耗一条命并满血复活」**不触发**，直接淘汰（`ignoreLives`）。
- **不被大贱客转移**：伤害管线对 `dtype: 'mental'` 跳过 transfer 阶段。
- **可被马保国太极判定反弹并反杀**；带 `noReflect` 的精神攻击不可反弹（目前为「不讲武德」）。**已被反弹过的伤害（`reflected`）不会再次被反弹**，反弹链终止。

| 持有者 | 触发 | tag |
|---|---|---|
| 大贱客 | 辱骂同一目标累计 3 次 | `insult` |
| 马保国 | 不讲武德：被杀后 5 局赢 ≥3 | `bujiangwude`（`noReflect`） |
| 大屁孩 | 暴走：判定历史三不同（回合最前，本人指定目标） | `berserk` |

不属于精神攻击：今日勇者运势 0/1 暴毙、大屁孩自爆、踢人/主动退出（这些不是伤害词条）。

**马保国**：血量 4 攻击 1。
- 混元形意太极：除大伊万爆、肉山坐（`noReflect` 标记的伤害）外，受到伤害时与**伤害来源各出一拳**判定（默认 `skillJudgeMode: 'player'`，对局暂停进入 `judge` 阶段；可选触发），赢则**原伤反弹**给来源。本次伤害在判定结束前**不结算**（挂起），判定结束后按结果补结算；反弹伤害带 `reflected` 标记，**不再触发反弹判定（反弹链终止）**。平局不算赢（正常承受伤害）。
- 闪电五连鞭：对同房间敌人进行 **5 局判定（双方各出 5 拳）**，按胜次造成其**当前血量** 20/40/60/80/100% 的伤害——**单次总量**（一条伤害事件；结算时取目标当前血量，而非最大血量）。
- 不讲武德：被击杀后与击杀者进行 **5 局判定（双方各出 5 拳）**，赢 ≥3 局则对击杀者发动**精神攻击**（见 4.2：秒杀、无视躲藏/命数；`noReflect`：不被太极反弹，也不被大贱客转移）；由不讲武德造成的死亡不再触发。

**伍六七（五六七）**：血量 3（作者确认 2026-11-24 的延迟三刀机制）：攻击 = **立刻前往任意指定房间**（可原地，移动即发生、之后按新位置结算），**下一回合的回合末**在该房间砍出 **三刀**（每刀 1 伤，AOE、命中躲藏/隐身、**不打自己**）。三刀逐段结算，目标为**刀落瞬间**该房间内的存活玩家（动态：蓄力期间走进来的会挨、走出去的不挨）；结算顺序为**其他行动之后、大伊万爆炸之前**，**平局回合同样落刀**。同一批内被致死、但因命数复活者（五条悟）**不再吃剩余刀**。刀落回合（蓄力回合）**无论伍六七是否赢下判定都不能进行其他行动**。大贱客的「回合末瞬时爆发全部吸收」同样适用于三刀（含其阵亡后的遗体吸收）。

**卖大伊万的小女孩**：血量 2、攻击 0（原稿血量/攻击栏均「-」，作者确认，Issue #6）；可向任意房间（含自己所在房间）投掷大伊万。**扔出当回合引信未开**；投掷后**第一个分出胜负的回合**引信激活（中间的平局回合顺延、不消耗炸弹；**领域让平局回合出现行动时仍是平局，同样顺延**，2026-11-24），该回合末检测目标房间内存活者——**含躲藏/隐身**（`aoe`，卡片原文「毁灭此房所有生物」）——造成极高伤害 **999999**（走普通扣血管线等效即死，原专用秒杀机制取消；`noReflect` 不触发太极反弹）。**炸弹先结算、后判胜**：激活回合末先把房间炸完再判胜负，可同归于尽平局（2026-11-21 用户确认，Issue #6；原 `ivanExplodeTiming` 配置移除）。

**大贱客**：血量 3。
- 被动「吸引全场伤害」：在场存活时，指向其他玩家的**非精神伤害**（含 AOE 伤害与延迟伤害；精神攻击见 4.2，不可转移）自动转移至大贱客；**仅转移伤害数值**，不转移附加效果/状态/控制；精神伤害不转移；已转移伤害不重复转移；转移后的伤害**视为直击大贱客——无视其自身的躲藏/隐身**（作者确认 2026-11-21）；**回合末瞬时爆发全部吸收**：回合末延迟事件结算期间（如大伊万爆炸），即使大贱客被吸收的伤害致死，同批剩余伤害仍全部由其（遗体）承担，被波及目标不受损；行动阶段的多段独立结算伤害不适用——大贱客死亡即停止吸收。**伍六七三刀属于回合末爆发，适用遗体吸收**（2026-11-24）。
- 攻击为辱骂（精神攻击，见 4.2）：**无视距离（任意房间）与躲藏/隐身**（作者确认 2026-11-21，A-06 定案）；对目标累计辱骂次数，**3 次即触发精神攻击击杀**（无视命数，可被太极反弹），致死后计数重置。

**大屁孩**：血量 **20**、攻击 **0**（作者确认 2026-11-24：暴走/自爆是唯一输出，普通攻击打不出伤害）。判定历史（每次判定子轮记录 赢/平/输）**跨回合记忆**：

- **结算时机（2026-11-24 作者确认）**：暴走 / 自爆不再在判定结算里当场执行，而是先「标记待结算」，在**判定结束之后、行动阶段之前**统一结算（回合最靠前），因此先于任何玩家行动。
- 连续三项出现**三种不同**结果（赢平输任意排列）→ **暴走**：进入 `trigger` 阶段，由**本人指定任意一名其他存活玩家**（任意房间，无视躲藏/隐身），对其释放**精神攻击秒杀**（见 4.2：伤害=结算时目标当前血量、无视命数；太极仍可判定反弹并反杀、大贱客不吸收精神伤害）；触发后历史清零。
- 连续三项**相同**（赢赢赢/平平平/输输输）→ **自爆**（自身立即淘汰、不伤及他人），同样在回合最前自动结算；触发后历史清零。
- **多名大屁孩同时暴走**：先进行一次**二次判定**（资格者亲自出拳，规则同行动排序：输者先）决定**暴走权顺序**，再按顺序逐个指定目标；中途被秒杀者失去其暴走权。
- **阵亡后不再触发**：同一子轮内先被淘汰时，后续追加的判定历史不会再以「尸体」身份引发暴走/自爆。

**无业游民（默认角色）**：无被动。

## 四、局外功能（不参与判定，2026-11-20）

以下能力属于观察/娱乐层，规则引擎的判定逻辑不因其存在而改变，任何一项目前关掉都不影响一局的对局结果。

### 1. 局内战绩（`PlayerStats`）
规则未对战绩做任何要求，本项为可读性改进：引擎在既有结算点上顺带累加，不新增判定分支。

| 字段 | 累计时机 |
|---|---|
| `throwWin` / `throwLose` / `throwTie` | 初次判定每个子轮结算后，按座位对全部对手记胜/负/平；全员同拳记平 |
| `damageDealt` / `damageTaken` | `applyDamage` 实际扣血值（按目标实际损失的 HP 计，不按标称伤害计） |
| `kills` | `eliminate` 被判定为击杀时（含命数耗尽） |
| `actions` / `heals` / `moves` | `submitAction` 成功执行对应类型时 |
| `roundsAlive` | 每回合推进时对仍存活的玩家 +1 |

统计只进入快照与回放帧，不参与排序、不参与胜负、不写入战斗日志。

### 2. 丢番茄小互动
- 三档道具：🍅 番茄、🥚 鸡蛋、🌹 鲜花，效果同为「砸一下」，仅动画与文案不同。
- 约束：仅存活玩家可投；不能砸自己；对局未开始或已结束不可投；同一玩家冷却 2.2s（`INTERACT_COOLDOWN_MS`）。
- **不写战斗日志、不改 HP、不占行动次数、不参与任何判定**，只走广播通道，客户端播完即弃。

### 3. 对局回放
- 录制方式：服务端在每次状态变化后计算状态签名，签名变化才记一帧（去重），每局上限 1500 帧，每房间保留最近 5 局。
- 帧内容 = 该时刻的公开快照（座位、血量、房间、阶段、已结算的出拳揭示、行动顺序、日志）。
- **不录 `pendingThrows`**：回放里出现的拳种全部来自 `judgeRecords`，因此回放不会泄露当时尚未结算的出拳。
- 进行中的对局可实时观看（列表里标「● 进行中」），对局结束后自动转为可回放的归档记录。

### 4. AI 难度
- 三档：`easy`（随机）/ `normal`（简单反制 + 收益优先）/ `hard`（全史出拳频率反制 + 威胁排序 + 补刀）。
- AI 通过与真人**相同的** `submitThrow` / `submitAction` 接口行动，不读取 `pendingThrows`；`hard` 档用的历史仅来自已结算并已公开的 `throwHistory`。
- 所有随机性走座位随机流（`RNG`），固定种子下 AI 行为可完全复现。
