# 拔典 · 已知问题与限制

## 功能限制

1. **二次判定为服务端代掷出拳**（`secondJudgeMode: 'serverRoll'`）：玩家手动出拳模式留有引擎配置位但未做 UI 流程（多子轮递归判定的人机交互复杂，首版简化）。规则假设 A-02。
3. **技能内判定均为服务端种子代掷**（太极/五连鞭/不讲武德）：原稿未明确判定方式。规则假设 A-03。
4. **仅实现 11 个角色**（9 首轮验证 + 老大爷 + 默认）：约 130 个原稿角色未实现；角色注册表已支持即插即用扩展。
6. **皇家幽灵式「隐身」状态**引擎已支持（`invisible` 字段），但无角色主动产生隐身（拔棍的「无视隐身」在纯躲藏场景同样生效并经测试）。

## 环境限制（本次执行环境）

7. **手机端适配**（2026-11-20）：首页/大厅/游戏三页面在 390px 视口零横向溢出（Playwright iPhone 视口截图回归）。建议体验分辨率 ≥360px；极窄屏（<360px）未做专项优化。
7b. **手机直连入口**：本服务器 Azure NSG 只放行 22/11937/8881-8892（sing-box 在用）；游戏已挂载 `http://<IP>:11937/badian/`（nginx 子路径反代+WebSocket）。隧道域名（trycloudflare）在中国大陆网络可能不稳定。
8. **真实 Chromium 端到端点击测试已完成**（2026-11-19：用户授权 sudo，安装系统库后解锁）。systemd 服务 badian.service 已配置（开机自启/崩溃重启）。注意：快速隧道（trycloudflare）地址在服务器重启后会变化——隧道已由 systemd 服务 `badian-tunnel` 托管（开机自启/崩溃重启），新地址自动写入项目根目录 `TUNNEL_URL.txt`。稳定地址需 Cloudflare 命名隧道（见 docs/OPTIMIZATION_PLAN.md P2-5）。
8. **未部署公网**：本地生产模式（`npm start`，:3100）验证通过；联机部署需自行提供 HTTPS 反代（Socket.IO 客户端用同源相对路径连接）。

## 素材说明

- 游戏王风角色卡为用户提供的原创卡面（9 张）；其中「今日勇者」卡面印刷文案为旧版（"技能资料缺失"），实际规则已更新为运势表+第一回合限一次——以游戏内详情弹层与 docs/GAME_RULES.md 为准，卡面 PNG 文字后续由素材层更新。
- 默认角色（无业游民）无卡面立绘，使用 CSS 绘制占位卡面。

## 设计约束

9. **二次判定/隐藏提交在极端平局时可能连续多轮重判**：引擎有 10000 子轮安全上限（理论上真人玩家几乎不可能触达）。
10. **行动队列含已淘汰者时**：推进时跳过，UI 队列显示灰化——若全员在行动前死亡，回合直接结束（符合规则）。
11. **平局（全员同灭，如大伊万同时毁灭所有人）时显示平局**，无胜者。
12. **房间人数上限 20**（UI 层）；引擎无硬上限。
13. **游戏结束后 pending 大伊万被取消**（不再结算）；规则假设记录在 GAME_RULES A-04 备注。
