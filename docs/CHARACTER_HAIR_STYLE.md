# 角色低模发型增强标准

全员角色 rig 在 `head` / `headTop` 挂点上叠加一层程序化低模发型几何，补足束发、鬓角、后脑发量、短发发际线与刘海体积。脸、服装、道具、动作与脚底锁定一概不动，几何随头/头顶关节同步；沿用原发色与顶点色平面着色，无新增贴图或外部模型资产。

实现入口：`client/src/battle3d/characters/hair-style.ts`；挂接位置：`characters/index.ts` 的 `createCharacterAsset`（专用 rig 工厂路径统一调用，幂等）。

## 锁定原则

三名样板先定锚点，再推广全角色。所有增强件只挂在 `head` 与 `headTop`，沿用角色原发色；脸、衣、道具、动作与脚底锁定不改。各造型几何参数集中在 `HAIR_STYLES` 与 `buildTopknot / buildShort / buildTwin / buildSpiky / buildElder / buildSlick / buildKid` 构造器中。

## 样板标准

| 角色 | 造型信号 | 增强规则 | 复核重点 |
|---|---|---|---|
| 吹箫哥 | 束发、绿袍、竹箫 | 扩大发髻；补鬓角、后脑发量；发顶加厚 | 正面看发髻轮廓，背面看后脑发量，侧面看鬓角；抬箫动作不变 |
| 拔棍 | 利落短打、小髻、腰带 | 明确短发发际线；补后脑轮廓与短发顶；小髻收整 | 收棍状态只看头部与站姿可辨；拔棍状态道具不遮脸 |
| 大伊万 | 橙衣、矮个、双马尾、怀中炸弹 | 刘海与两侧头发加体积；后脑补发量；发梢与肩线拉开 | 选角看刘海；俯视下炸弹与头部轮廓都在 |

## 推广规则

| 类型 | 角色 | 规则 |
|---|---|---|
| 束发髻 | 吹箫哥、马保国 | 髻体按角色比例缩放；补鬓角与后脑；发带用角色已有配色 |
| 短发 / 平头 | 拔棍、伍六七、今日勇者、无业游民 | 明确发际线；后脑补厚度；保留头巾 / 发带 / 骰子等头顶语义 |
| 体积刘海 / 发束 | 大伊万 | 刘海分片加厚；两侧发量外扩；脸与衣服之间留出暗色轮廓 |
| 原有强发量 | 五条悟 | 只补后脑厚度与背向发片，不遮挡眼罩与原发束 |
| 头部配件优先 | 老大爷、大贱客 | 斗笠 / 磁环下的发量只做轮廓补强，不抢配件识别 |
| 大头比例 | 大屁孩 | 圆润发帽随头放大，保留呆毛 |

## 挂点与开关

- 挂点：`head`（发帽、发际线、鬓角、后脑、发束、刘海）、`headTop`（发髻、小髻、呆毛；缺失时只挂 head）。
- 网格命名 `hairStyleV2Mesh`，组名 `hairStyleV2_head` / `hairStyleV2_top`，便于取证定位。
- 幂等：同一 rig 重复挂接不会叠加几何。
- 新旧对照 / 回退：`setCharacterHairStyle(rig, false)` 关闭、`true` 恢复。

## 验收口径

- 三视图：正面、侧面、背面均有旧版 / 新版同机位对照，右列侧面 / 背面须为真实新版而非回退旧模型。
- 选角：竖屏取景下发型可辨，角色不被技能面板遮挡。
- 战场：俯视机位下能靠头部轮廓、发色与道具认出角色。
- 回归：11 名角色切换无脚本错误；四段流程、准备态与战场带入不受影响。
