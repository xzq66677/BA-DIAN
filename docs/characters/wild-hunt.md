# 狂猎 · wild-hunt（Issue #71 · 本地待评审）

规格：charId `wild-hunt`，血 4、攻击 1（`attackType: 'melee'`；骑乘时攻击钩子接管，可跨房间突进）。
视觉：暗红主体 `0x7a2f2f` + 金色点缀 `0xd8b04a`，程序化「长枪 + 骑旗」道具（`prop: 'lance'`，`rig.ts` 新增），
身高 1.02；无专属立绘（`cards.ts` 占位卡，`no: '—'`）。

## 规则

- **受击判定**（受到 `isAttack` 伤害时）：与来源猜拳，**双方亲自出拳**（默认 `skillJudgeMode: 'player'`，对局进入 `judge` 阶段），
  **平局立即重掷直到分出胜负**：
  - **赢**：本次攻击伤害**完全抵消**，反击来源——
    - 未骑乘：反击 **1** 伤，并**上马 1 回合**；
    - 已骑乘：反击改为 **6** 伤，**使用后立即下马**；
  - **输**：正常承受本次伤害。
  - 燃烧、大伊万爆炸、精神攻击等非「攻击」伤害**不触发**判定；AI 对局/测试场可切 `serverRoll` 即时结算。
- **骑乘**：攻击**无视距离**（可锁定任意房间目标）并**带位移**（攻击后移动到目标房间），伤害 **×2**。
- **爆发回合**：骑乘的**最后一回合**攻击变为 **6 伤单体**（仍带位移），**同样叠加击杀加成**（1 杀 → 9 伤）。
- **主动上马**：消耗一次行动，上马 **2 回合**（当回合起算；之后两个回合为骑乘回合，第二回合即爆发回合）。
- **猎杀成长**：每次**击杀**敌人后攻击 **×1.5**（可叠加：1 杀 ×1.5、2 杀 ×2.25…）；与骑乘 ×2 相乘。

## 实现要点

- `DamageRequest.isAttack`（新增）：普攻、燃烧箭、被操控攻击会标记；狂猎 `onBeforeDamage` 只处理该标记的伤害。
- 受击判定走技能判定系统：player 模式返回 `{ deferTo: { kind: 'wildhunt', rounds: 1, rerollTie: true, resolve } }`，
  引擎挂起本次伤害并暂停进入 `judge` 阶段；**平局不推进局数、双方重新出拳**（`SkillJudgeOptions.rerollTie`）；
  赢 → 反击 + 上马/下马（不补结算原伤害）；输 → 以 `judgeResolved: true` 补结算原伤害（不再触发判定）。
  `serverRoll` 模式（AI 对局/测试场）则即时用 `rollJudgeThrows` 循环重掷直到分出胜负。
- 反击伤害 `tag: 'counter'`、`ignoreHide: true`，且不标记 `isAttack`（避免触发对方的受击判定/反击链）。
- 骑乘用状态 `mounted`（`statuses.ts`）：`remainingRounds` 交由引擎回合末递减，到期移除时 `cleanup` 自动下马；
  `charState.mountExpiresRound` 记录爆发回合，`onAttackAction` 读取 `mounted / mountExpiresRound / kills` 计算伤害。
- 攻击完全由 `onAttackAction` 接管（未骑乘时限制同房间近战；骑乘时跨房间突进并位移），伤害日志与 `onAttackLanded` 照常触发。
- 击杀成长走 `CharDef.onKill` 钩子（引擎 `eliminate` 在击杀者统计后调用），因此反击/普攻击杀都能成长。
- AI：`aiStrategy` 未骑乘先「上马」，骑乘后追杀血量最低的可见目标；`judge` 阶段由服务端 AI 自动出拳。

## 规则假设（待作者确认）

1. 受击判定默认 **player 模式**（双方亲自出拳、对局暂停进入 `judge`）；平局按「再来一把」重赛且不推进局数。
2. 「上马两回合」按「当回合起算、之后两个回合为骑乘回合」实现，第二回合为 6 伤爆发回合。
3. 击杀加成永久叠加（1.5^击杀数），与骑乘 ×2 相乘；**爆发回合 6 伤同样叠加击杀加成**（用户 2026-11-26 确认）。
