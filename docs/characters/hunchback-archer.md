# 佝偻弓箭手 · hunchback-archer（Issue #71 · 本地待评审）

规格：charId `hunchback-archer`，血 3、远程攻击 1（`attackType: 'ranged'`，**可射击同房间目标**，不提供近战）。
视觉：骨灰绿主体 `0x6f7a5a` + 骨白点缀 `0xe8e2cf`，程序化「骨柄长弓」道具（`prop: 'bow'`，`rig.ts` 新增），
身高 0.96；无专属立绘（`cards.ts` 用占位卡，`no: '—'`）。

## 规则

- **燃烧箭（普攻）**：远程攻击（同房间/异房间均可）命中造成 1 点伤害并**点燃**目标。
  - 燃烧：每回合末结算 **0.5** 伤害（**平局回合同样结算**），无限持续，直到目标消耗一次行动「扑灭火焰」；
  - 被点燃的当回合与扑灭的当回合**不结算**（`appliedRound` 保护 + 状态移除）；
  - 燃烧伤害为 `special` + `noReflect`：不触发太极反弹/大贱客转移。
- **骷髅身躯**：受到**精神伤害以外**的伤害导致血量归零时不会死亡：
  - **完整缺席 1 回合**：倒地当回合之后的那个回合整回合不能行动（保持存活、**仍参与猜拳**、平局也计入）；
  - **再下一回合开始时**以**生命上限一半**（3 → 1.5）复原；
  - **因燃烧导致血量归零 → 彻底死亡**；燃烧期间受到其他伤害致死**仍可复原**；
  - 精神伤害致死 → 正常死亡（不倒地）。
- **无法主动回血**：不能使用基础行动「回复」（`blockBaseActions: ['heal']`）。
- **引燃骷髅**（环境行动）：与弓箭手同房间的**燃烧敌人**可消耗一次行动，把火引到它身上（使其燃烧）。
- **取燃烧箭 / 燃烧箭近战**（环境行动）：与弓箭手同房间的**任何敌人**：
  - 消耗 **2 次行动**「取出燃烧箭」（进度 1/2 → 2/2）；
  - 再消耗 **1 次行动**「燃烧箭近战」，造成 1 伤 + 点燃（与弓箭手普攻效果相同）；
  - **攻击一次后箭失效**（需重新取箭）；
  - 取箭期间**被弓箭手普攻命中** → 进度清零（中断）。

## 实现要点

- 状态走统一注册表 `shared/src/statuses.ts`（`burning` 的 tick/actions/cleanup），引擎负责生命周期；
  快照只下发公开字段（`PlayerState.effects` → `PublicStatusEffect`），客户端读取器
  `client/src/battle/status-readers.ts`（`status-burning`）负责展示。
- 环境行动由 `CharDef.extraActionsForOthers` 提供、`statuses.ts` 的 `actions` 提供，引擎聚合成
  `extraActions` 随快照下发当前行动者；客户端只渲染、服务端重新校验。
- 倒地/复原：`CharDef.onLethalDamage / skipsAction / onRoundStart`，引擎在伤害结算、队列推进、回合开始时调用。
- 中断：`CharDef.onAttackLanded` 在普攻命中后回调（反弹/未命中不触发）。

## 规则假设（待作者确认）

1. 「完整缺席 1 回合」按「倒地当回合之后的那个回合整回合不能行动」实现，再下一回合开始复原。
2. 弓箭手阵亡后不再提供「取箭/燃烧箭」行动（已取出的箭也随之失效）。
