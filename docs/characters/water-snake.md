# 飞天水螅 · water-snake（Issue #71 · 本地待评审）

规格：charId `water-snake`，血 3、攻击 1.5（`attackType: 'melee'`）。
视觉：水青主体 `0x2f6f7a` + 浅水点缀 `0x9fd8e8`，程序化「水螅触手」道具（`prop: 'tentacle'`，`rig.ts` 新增），
身高 1.04；无专属立绘（`cards.ts` 占位卡，`no: '—'`）。

## 规则

- **玄武岩高塔**（消耗一次行动）：需 **2 次行动**造完；塔在当前房间原地建成，**塔内外隔绝、算作新房间**。
  - 塔有 6 点耐久（数据结构预留，当前没有摧毁规则）；
  - 建成后飞天水螅自动进入塔内；塔内玩家不计入原房间成员（AOE、伍六七三刀等房间级效果不穿透塔壁）；
  - 塔内与塔外不能直接互相攻击（近战/远程都不行），只能靠**吸/吹**改变位置；离开塔内用普通移动。
- **塔内压制**：飞天水螅与敌人在塔内同处时，敌人行动前须判定（双方各掷一拳）：
  - **胜**：正常行动；
  - **平**：本次行动无效（仍消耗行动）；
  - **负**：改为攻击自己（用自身攻击力，仍消耗行动）。
- **吸 / 吹**（各消耗一次行动，每次只把一名敌人移动一格）：
  - **吸**：其他房间 → 自己房间；自己房间 → 塔内；
  - **吹**：塔内 → 自己房间；自己房间 → 其他房间（优先目标的初始房间，否则任选一个其他房间）；
  - 无法锁定躲藏/隐身的玩家。
- **亡魂**（死后继续参与）：首次致死不会真正死亡——hp 归零、**不可被攻击**、仍**参与猜拳与行动队列**，
  但只能使用「吸 / 吹」（或跳过）；仍计入存活（可以获胜）。

## 实现要点

- 高塔用 `charState` 标记：`towerBaseRoom`（塔所在原房间）、`buildProgress`、`inTower`；引擎新增 `isInTower`
  并在 `roomMembers` / `isSameRoom` 中把塔内视为独立房间：
  - `roomMembers(room)` 排除塔内玩家 → AOE/三刀/爆炸不穿透塔壁；
  - `isSameRoom(a,b)` 要求「同在塔内或同在塔外」；
  - `base-actions.actAttack` 在跨塔壁时直接拒绝（"高塔内外隔绝"）。
- 塔内压制走新增的 `CharDef.onBeforeAction`（引擎在 `submitAction` 执行行动前遍历提供者）：
  返回 `'block'` → 本次行动无效；`'selfAttack'` → 目标按自身攻击力自伤；两者都由
  `consumeSuppressedAction` 照常消耗行动并推进队列。判定用服务端即时猜拳（单掷，不重掷）。
- 吸/吹是普通角色技能（`targetHint: 'anyPlayer'`），只修改 `room` / `char.inTower`，不直接造成伤害。
- 亡魂用 `charState.posthumous`：`onLethalDamage` 首次致死改为 hp0 + `invisible`（不可被攻击）；
  `onBeforeDamage` 对亡魂直接 `'skip'`（AOE 也无效）；`validateAction` 限制亡魂只能吸/吹/跳过。
  `alive` 保持 true，因此仍参与猜拳、行动队列与胜负判定。
- 客户端：状态读取器新增「高塔 / 造塔中 / 塔内 / 亡魂」；攻击目标列表按塔内外过滤；
  `palette/rig` 新增水螅触手道具；`cards` 占位卡文案。

## 规则假设（待作者确认）

1. 造塔按「两次行动」实现（手写稿「胜两次造完」按「需两次」理解）；塔的 6 点耐久暂不可被摧毁。
2. 吹 = 推远一格（与吸方向相反）；吹出房间时优先回到目标初始房间，冲突时选任意其他房间。
3. 吸/吹每次行动只作用一名敌人；「可对多个人施加两种不同效果」暂按分多次行动实现。
4. 塔内压制判定用服务端即时猜拳（不进入出拳面板）；若希望像狂猎一样双方亲自出拳可再改。
5. 亡魂状态仍计入存活（可获胜）；「任意玩家」类技能（如鬼影附身、大贱客辱骂）目前未单独加塔壁隔离。
