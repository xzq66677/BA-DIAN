# 拔典（BA DIAN）

基于石头剪刀布的回合制多人生存游戏：每回合所有存活玩家**隐藏出拳**，胜者获得行动资格，依次执行移动 / 攻击 / 回复（角色技能可改写规则），最后一名存活玩家获胜。

- 代码仓库：<https://github.com/xzq66677/BA-DIAN>
- 认领看板：<https://xzq66677.github.io/BA-DIAN/WORKTREE-LIVE.html>（动手前先认领，见 [CONTRIBUTING.md](CONTRIBUTING.md)）

## 功能一览

- **真人联机**：Socket.IO 房间制，每房最多 10 人（本机玩家 + AI 合计）
- **单设备多人**：同一块屏幕轮流隐私出拳
- **二次判定**：行动资格者亲自出拳，逐子轮决定行动顺序
- **AI 三档难度**：休闲 / 普通 / 硬核，与真人走完全相同的引擎接口
- **15 名角色**：各自独立的被动与技能
- **3D 战场**：Three.js 低模人形 + 悬浮遗迹六棱石台；WebGL 不可用时自动回退 2D 牌桌
- **对局体验**：全局播报、战斗演出节奏、局内战绩、丢番茄、合成音效、横竖屏自适应、机制测试场
- **对局回放**：录制与播放器已实现，界面暂未启用（`Game.tsx` 中 `REPLAY_ENABLED = false`）

## 快速开始

环境：Node.js ≥ 20（跑测试需 ≥ 22.15）、npm ≥ 10。

```bash
npm install
npm run build        # 服务端 tsc + 客户端 vite
npm start            # 生产模式 http://localhost:3100（PORT 可覆盖）
```

```bash
npm run dev:server   # tsx watch 服务端 :3100
npm run dev:client   # vite dev 客户端 :5173（代理到 :3100）
```

**更新线上版本**：推送到 `main` 后，服务器每 2 分钟自动拉取、构建并重启（`badian-autodeploy.timer`）。需要立即生效时在服务器执行 `npm run deploy`。详见 [docs/DEPLOY.md](docs/DEPLOY.md)。

## 玩法

1. **初次判定**：所有存活玩家同时隐藏出拳，服务端统一揭示。平局 / 三人循环算一个独立平局回合（无人行动，回合末照常结算）；分出胜负时胜者获得行动资格。
2. **二次判定**：资格者 ≥2 人时亲自出拳排序，输者整组先动、赢者整组靠后，平局同组重出拳；不剥夺行动资格，领域与角色判定历史不参与排序。仅 1 名资格者时直接行动。
3. **行动阶段**：按队列各执行一次行动——移动（到任意玩家初始房间）/ 攻击（默认同房间近战 1 伤）/ 回复（回满血）/ 角色技能；躲藏、找出来为可选基础行动。
4. **回合末**：延迟事件结算（如大伊万爆炸），并输出回合小结。
5. HP 归零立即淘汰；最后一名存活玩家获胜。

**超时**只在房间内有 ≥2 名真人时生效（出拳 30s 代掷、行动 45s 跳过）；单人 vs AI、单设备多人都不布防。

### 入口模式

- **默认（电影感入口）**：开场 → 主菜单 → 作战室 → 选角 → 战场交接，选角后弹房间设置（昵称、本机玩家数、AI 数量、天气）。`?stage=<id>` 可切换入口地图。
- **经典入口**：`?entrance=classic`，TCG 卡桌风格界面。
- **视觉原型**：`?proto=A|B|C`，同一真实引擎对局的三种构图原型。

## AI 难度

房主在大厅卡位区选择，整局统一生效。AI 只读取**已结算并公开**的判定历史，固定种子下行为完全可复现。

| 难度 | 出拳策略 | 行动策略 |
|---|---|---|
| 休闲 | 纯随机 | 能打就打，否则随机移动 |
| 普通 | 反制上一轮对手的出拳，掺随机 | 优先补刀残血、自己残血先回复、远程优先异房间 |
| 硬核 | 统计全场已结算出拳频率，出最可能反制的手势（30% 扰动） | 按威胁值选目标，优先收人头，技能与站位收益最大化 |

## 项目结构

```
shared/src/     规则引擎（独立于前端与网络层）
  characters/   角色注册表
  testcases/    共享测试用例（vitest 与网页测试场同源）
server/src/     Socket.IO 服务端（房间 / 隐藏提交 / 断线重连 / AI / 互动 / 回放录制）
client/src/     React 前端（入口 / 大厅 / 游戏页 / 回放 / 测试场）
  battle/       事件解析 + 演出队列 + 音效 + 播报视图
  battle3d/     3D 战场（场景 / 人形 rig / 布局 / 特效 / 镜头）
tests/          自动化测试（引擎 / socket 集成 / AI / UI / battle3d / E2E）
docs/           规则、架构、部署、测试报告、角色视觉记录与截图取证
scripts/        地图采样、对局验收、视觉取证等工具脚本
```
