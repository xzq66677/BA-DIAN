# 拔典（BA DIAN）· 多人房间制生存游戏

基于石头剪刀布的回合制多人生存游戏。

> 代码仓库：https://github.com/xzq66677/BA-DIAN每回合所有存活玩家隐藏出拳判定行动资格，胜者再判定行动顺序，依次执行移动/攻击/回复（角色技能可改变规则），最后一名存活玩家获胜。

支持：真人联机（Socket.IO 房间制）、单设备多人（隐私出拳）、AI 玩家、10 个角色（9 个首轮验证角色 + 老大爷）、机制测试场。

## 环境要求

- Node.js ≥ 20（开发验证使用 v24.21.0）
- npm ≥ 10

## 本地运行

```bash
# 1. 安装依赖
npm install

# 2. 全量自动化测试（103 用例）
npm test

# 3. 构建（服务端 tsc + 客户端 vite）
npm run build

# 4. 启动（生产模式：服务端 + 静态客户端）
npm start
# → http://localhost:3100（端口可用环境变量 PORT 覆盖）
# 本机已配置 systemd 服务（开机自启/崩溃重启）：
#   sudo systemctl restart badian && journalctl -u badian -f
#
# 本机多种访问方式（本服务器实机部署时）：
#   直连:       http://<服务器IP>:3100（需云防火墙放行）
#   nginx路径:  http://<服务器IP>:11937/badian/（NSG已放行，手机直连可用）
#   公网隧道:   https://<trycloudflare地址>（见 TUNNEL_URL.txt）

# 开发模式（可选）
npm run dev:server    # tsx watch 服务端 :3100
npm run dev:client    # vite dev 客户端 :5173（代理到 :3100）
```

打开浏览器访问 `http://localhost:3100`（TCG 卡桌风格界面：深色卡桌 + 游戏王风角色卡 + 技能卡行动坞）：

- **大厅**：房间列表实时刷新、点击加入；角色卡池展示墙（点击看卡面与台词；无立绘角色显示占位卡）
- **AI 选角**：房主添加 AI 时可指定角色或随机（默认随机）；房主可随时更改已加入 AI 的角色
- **对局内**：行动特效（卡牌上弹出⚔️/💊/🚶/✨动画）、局内发言（底部常驻面板，实时同步，可收起）、房主可踢人（点卡牌详情里的踢出按钮，对局中被踢=淘汰）
- **房间管理**：房主可解散房间（全员退出）；玩家可随时退出房间（对局中退出=淘汰出局）；胜负判定为全屏弹层（胜者卡面+再来一局）；昵称必填且本设备记忆

- **单人开局**：填昵称 + AI 数量 → 直接开局
- **创建房间**：获得 4 位邀请码 → 朋友在「加入房间」输入码加入 → 房主开始游戏
- **单设备多人**：「本机玩家数」选 2 以上 → 出拳阶段按提示传递设备，每人亲自出拳（提交后不回显拳种）
- **机制测试场**：首页入口，运行全部测试用例（PASS/FAIL、种子复现、完整结算日志）

## 游戏流程

1. **初次判定（隐藏出拳）**：所有存活玩家同时出拳；服务端统一揭示判定。平局/三人循环全员重判，胜者（可多名）获得行动资格。
2. **二次判定（行动排序）**：资格者判定排序，输者优先行动；不剥夺资格。
3. **行动阶段**：按队列依次执行一次行动 —— 移动（到任意玩家初始房间）/ 攻击（默认同房间近战1伤）/ 回复（回满血）+ 角色技能；躲藏/找出来为可选基础行动。
4. **回合末**：延迟事件结算（如大伊万爆炸，动态判定房间成员）；每回合输出「回合小结」重点摘要。
5. HP 归零立即淘汰；最后一名存活玩家获胜。

## 角色（9 首轮验证 + 老大爷 + 默认）

| 角色 | 机制摘要 |
|---|---|
| 拔棍 | 需先「拔棍」才能造成伤害；攻击无视躲避（含隐身/躲藏） |
| 吹箫哥 | 仅能远程（异房间），需先「瞄准」；无法近战 |
| 五条悟 | 近3/远2（远需瞄准）；领域展开后远程免瞄准、平局算胜；领域对冲 |
| 老大爷 | 近3远2；领域展开后平局算胜、强化后近5远3；与五条悟对冲 |
| 马保国 | 混元形意太极（受伤判定反弹原伤）；闪电五连鞭；不讲武德（死后5局赢3带走对面） |
| 伍六七 | 3段AOE：每段对攻击时所在房间所有玩家1伤，段独立结算 |
| 卖大伊万的小女孩 | 向任意房间投掷大伊万，回合末爆炸毁灭爆炸时房间内全部玩家（动态判定成员） |
| 今日勇者 | 技能「抽取今日运势」（仅第一回合可用，每局限一次）：掷0-9——0/1暴毙；2/3→血1攻1；4/5→血3攻1；6→血4攻2；7→血5攻3；8→血6攻4；9→血6攻6 |
| 大贱客 | 被动吸引全场非精神伤害（仅转移伤害不转移效果）；辱骂同一人3次致死；辱骂无视躲避 |
| 大屁孩 | 判定历史连续三不同（赢平输）→暴走精神攻击；三连相同→自爆；跨回合记忆 |
| 无业游民 | 默认角色，无被动 |

角色原始数据来自附件《拔典1/2_角色速查表》（OCR 整理版），存疑处已在 `docs/GAME_RULES.md` 标注规则假设。完整原始数据见 `docs/角色速查表-原始数据.md`。
