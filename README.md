# 拔典（BA DIAN）· 多人房间制生存游戏

基于石头剪刀布的回合制多人生存游戏。

> 代码仓库：https://github.com/xzq66677/BA-DIAN每回合所有存活玩家隐藏出拳判定行动资格，胜者再判定行动顺序，依次执行移动/攻击/回复（角色技能可改变规则），最后一名存活玩家获胜。

支持：真人联机（Socket.IO 房间制）、单设备多人（隐私出拳）、AI 玩家（休闲/普通/硬核三档难度）、10 个角色（9 个首轮验证角色 + 老大爷）、**3D 战场**（Three.js 低模人形 + 六棱石台房间，WebGL 不可用自动回退 2D 牌桌）、局内战绩统计、丢番茄小互动、横屏/竖屏自适应、机制测试场。

## 环境要求

- Node.js ≥ 20（开发验证使用 v24.21.0）
- npm ≥ 10

- **对局内（2D 牌桌 / 3D 不可用回退）**：斗地主式牌桌布局（上方对手座位条 / 中央牌桌与出拳揭示台 / 底部我的席位与手牌 / 右侧战斗日志）；WebGL 上下文丢失时自动无感回退 2D，对局不中断；**出拳揭示**——每轮判定结算后所有人可见彼此的石头剪刀布（提交期间保密封锁，公平不破坏）；**战斗演出**——受击斩击（弹出+斜向斩击+冲击闪光+伤害飘字+HP条平滑下降）、回复柔光、移动飞行动画（卡片跨房间 FLIP）、淘汰印章/复活爆发、AOE 房间告警、**大伊万完整演出链**（投掷物从投掷者卡面飞向目标房间 → 落点冲击波 → 房间内成员逐个结算；爆炸前目标房间持续显示「💣 预计第 N 回合末爆炸（平局顺延）」待爆警示），全部由服务端结构化事件经演出队列驱动（不快照差分猜测）；演出可 1×/2×/4× 倍速、跳过本段、全部跳过；局内发言（底部常驻面板，实时同步，可收起）、房主可踢人（点卡牌详情里的踢出按钮，对局中被踢=淘汰）
- **终局演出**：胜负判定弹层——胜者聚光+一次性金色光屑+结果摘要（终局回合/出局人数）；平局使用独立冷灰构图；关闭弹层后战场进入终局态（胜者卡金色光环+👑、空房间弱化），横幅显示完整结果；可随时「查看战场」跳过
- **音效（可关）**：WebAudio 实时合成的轻量原创音效（受击/回复/移动/淘汰/爆炸/胜利等，与结构化事件绑定），顶栏 🔊/🔇 开关，默认开启、音量克制；拥堵时自动只保留重大事件音效，系统「减少动态效果」时同步精简；零素材/零网络加载
- **局内战绩**：顶栏「📊 战绩」打开统计面板，逐人显示出拳胜/负/平、造成与承受伤害、击杀数、行动次数、回复次数、移动次数、存活回合、被番茄砸中次数
- **丢番茄**：点座位上的 🍅（或卡牌详情里的 🍅/🥚/🌹）向任意存活玩家投掷，全房间可见飞行与命中动画，对方座位累计被砸次数；纯娱乐，**不进战斗日志、不改血量、不影响判定**，同一玩家 2.2 秒冷却
- **对局回放（已完成，暂未启用）**：录制与播放器已实现（状态帧去重、逐帧播放、0.5–4× 倍速、导出 JSON），但按 2026-11-20 要求**暂不发布、界面不挂入口**（`Game.tsx` 内 `REPLAY_ENABLED = false`，置 true 即恢复）；服务端录制逻辑保持不变，历史数据不受影响
- **`prefers-reduced-motion`**：系统开启「减少动态效果」时，演出自动降级为最短时长、无震动/闪烁的轻反馈；终局弹层光效/光屑静止、投掷物飞行隐藏，信息保持完整
- **屏幕适配**：手机横放（≤560px 高）自动切换紧凑牌桌——座位条压缩、中央分栏、手牌横向可滑、日志与发言改为可收起抽屉；手机竖屏隐藏侧栏并把牌桌改为内部滚动，保证「开始出拳」按钮始终一屏可见；桌面端整桌单屏不滚动
- **房间管理**：房主可解散房间（全员退出）；玩家可随时退出房间——**整台设备退出**（单设备多人的全部身份一起移除，对局中=引擎内淘汰公示），退出后房间无真人可继续（空/只剩 AI）则**默认解散**，仍有其他真人则对局继续；同一设备不能重复加入同一房间（不会出现两个自己）；首页被旧房间占用时提供「回到房间 / 退出旧房间」一键解除；胜负判定为全屏弹层（胜者卡面+再来一局）；昵称必填且本设备记忆

- **单人开局**：填昵称 + AI 数量 → 直接开局
- **创建房间**：获得 4 位邀请码 → 朋友在「加入房间」输入码加入 → 房主开始游戏
- **单设备多人**：「本机玩家数」选 2 以上 → 出拳阶段按提示传递设备，每人亲自出拳（提交后不回显拳种）
- **机制测试场**：首页入口，运行全部测试用例（PASS/FAIL、种子复现、完整结算日志）

## AI 难度

房主在大厅卡位区选择，整局统一生效。AI 与真人走**完全相同的引擎接口**（`submitThrow` / `submitAction`），不存在偷看隐藏出拳或直接改状态的作弊路径——难度差异只体现在「出拳策略」与「行动优先级」上。

| 难度 | 出拳策略 | 行动策略 |
|---|---|---|
| 🤖 休闲 | 纯随机 | 能打就打，否则随机移动；不会用技能组合 |
| 🤖 普通 | 上一轮对手的出拳做简单反制（出能赢它的拳），掺随机 | 优先击杀残血目标、残血自己优先回复、远程角色优先异房间目标 |
| 🤖 硬核 | 统计全场**已结算**出拳的频率分布，出最可能反制的手势（30% 概率扰动，避免被读死） | 威胁值排序（血量/攻击力/是否可秒）选目标，优先补刀收人头，技能与站位都按收益最大化 |

关键约束：AI 只在 `roundEnd` 之后、或自己出手时读取**已经结算并公开**的判定历史，因此难度提升不破坏隐藏出拳的公平性。所有随机数取自 `shared/src/rng.ts` 的座位随机流，固定种子下 AI 行为完全可复现（回放/测试同源）。

## 局外功能对规则的影响

战绩、丢番茄互动（以及暂未启用的回放）均为**只读观察层**，不进入判定：

- 战绩字段由引擎在结算时累计（`PlayerStats`），只做展示，不参与任何伤害/胜负计算
- 互动事件只走广播通道，不写 `game.logs`、不改 hp、不占行动次数
- 回放（暂未启用）是「状态帧录制」——服务端在状态签名变化时记一帧（每局上限 1500 帧、每房间保留最近 5 局），播放端只渲染帧，不回放隐藏出拳（`reveal` 字段始终来自已结算记录）

## 操作与超时

- **自身技能不需要选目标**：`targetHint: 'none'` 的技能（领域展开 / 抽取今日运势 / 领域强化 / 拔棍开关）选中后，确认条只剩「已选【技能】· 确认发动 · 取消」，不再要求点战场高亮卡牌，「确认发动」也不会因为没有目标而置灰。只有指向性技能（攻击 / 瞄准 / 找出来 / 五连鞭 / 投掷大伊万）才需要选目标或房间。
- **超时只在「有人等」时生效**：出拳 30s 代掷、行动 45s 跳过（可配置），但**仅当房间内有 ≥2 名真人**才布防。单人 vs AI 没有超时这回事——AI 是即时应答的，没有任何人在等你，你的回合不会被系统代掷或自动跳过；单设备多人（同一块屏幕）同样不布防。
- **AI 永不卡局**：AI 决策本身走「候选行动链」（非法就换下一个，最差 `skip`）；房间另有 1.2s 的 AI 看门狗，只要还停在该 AI 出拳/行动，就补驱动一次——它只驱动 AI、绝不替真人操作，因此取消超时也不会让对局僵死。
- **同一房间连打多局**：重开时战斗日志清空重来（服务端下发 `gameNo`，客户端据此清空），日志序号 `seq` 整个房间内单调递增（不随每局归零），因此第二局之后增量推送与去重都正常，不会出现「第二局日志不再更新」。

## 游戏流程

1. **初次判定（隐藏出拳）**：所有存活玩家同时出拳；服务端统一揭示判定。平局/三人循环算一个独立的平局回合（无人行动，回合末照常结算并翻页），下一回合重新判定；分出胜负时胜者（可多名）获得行动资格。
2. **二次判定（行动排序）**：资格者判定排序，输者优先行动；不剥夺资格。
3. **行动阶段**：按队列依次执行一次行动 —— 移动（到任意玩家初始房间）/ 攻击（默认同房间近战1伤）/ 回复（回满血）+ 角色技能；躲藏/找出来为可选基础行动。
4. **回合末**：延迟事件结算（如大伊万爆炸，动态判定房间成员）；每回合输出「回合小结」重点摘要。
5. HP 归零立即淘汰；最后一名存活玩家获胜。

| 角色 | 机制摘要 |
|---|---|
| 拔棍 | 需先「拔棍」才能造成伤害；攻击无视躲避（含隐身/躲藏） |
| 吹箫哥 | 仅能远程（异房间），无需瞄准直接攻击；无法近战 |
| 五条悟 | **2条命**（首次致死满血复活）；近3/远2（远需瞄准）；领域展开后远程免瞄准、平局算胜（领域全场唯一，后展开覆盖先展开） |
| 老大爷 | 近3远2；领域展开后平局算胜、强化后近5远3；后展开的领域覆盖先展开的领域 |
| 马保国 | 混元形意太极（受伤判定反弹原伤）；闪电五连鞭；不讲武德（死后5局赢3带走对面） |
| 伍六七 | 3段AOE：每段对攻击时所在房间所有玩家1伤，段独立结算 |
| 卖大伊万的小女孩 | 向任意房间投掷大伊万；投掷回合不炸，投掷后第一个分出胜负回合末爆炸（平局顺延），毁灭爆炸时房间内全部玩家（含躲藏者；动态判定成员；炸完后才判胜负，可同归于尽） |
| 今日勇者 | 技能「抽取今日运势」（全局仅可用一次、不限回合）：掷0-9——0/1暴毙；2/3→血1攻1；4/5→血3攻1；6→血4攻2；7→血5攻3；8→血6攻4；9→血6攻6 |
