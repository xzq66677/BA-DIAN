# 拔典（BA DIAN）· 多人房间制生存游戏

基于石头剪刀布的回合制多人生存游戏。

> 代码仓库：https://github.com/xzq66677/BA-DIAN每回合所有存活玩家隐藏出拳判定行动资格，胜者再判定行动顺序，依次执行移动/攻击/回复（角色技能可改变规则），最后一名存活玩家获胜。

支持：真人联机（Socket.IO 房间制）、单设备多人（隐私出拳）、AI 玩家（休闲/普通/硬核三档难度）、10 个角色（9 个首轮验证角色 + 老大爷）、局内战绩统计、丢番茄小互动、对局回放、横屏/竖屏自适应、机制测试场。

## 环境要求

- Node.js ≥ 20（开发验证使用 v24.21.0）
- npm ≥ 10

打开浏览器访问 `http://localhost:3100`（TCG 卡桌风格界面：深色卡桌 + 游戏王风角色卡 + 技能卡行动坞）：

- **大厅**：房间列表实时刷新、点击加入；角色卡池展示墙（点击看卡面与台词；无立绘角色显示占位卡）
- **AI 选角**：房主添加 AI 时可指定角色或随机（默认随机）；房主可随时更改已加入 AI 的角色
- **AI 难度**：房主在卡位区切换「休闲 / 普通 / 硬核」，本局所有 AI 统一生效（详见下文）；非房主看到当前难度的只读标签
- **对局内**：斗地主式牌桌布局（上方对手座位条 / 中央牌桌与出拳揭示台 / 底部我的席位与手牌 / 右侧战斗日志）；**出拳揭示**——每轮判定结算后所有人可见彼此的石头剪刀布（提交期间保密封锁，公平不破坏）；行动特效（卡牌上弹出⚔️/💊/🚶/✨动画）、局内发言（底部常驻面板，实时同步，可收起）、房主可踢人（点卡牌详情里的踢出按钮，对局中被踢=淘汰）
- **局内战绩**：顶栏「📊 战绩」打开统计面板，逐人显示出拳胜/负/平、造成与承受伤害、击杀数、行动次数、回复次数、移动次数、存活回合、被番茄砸中次数
- **丢番茄**：点座位上的 🍅（或卡牌详情里的 🍅/🥚/🌹）向任意存活玩家投掷，全房间可见飞行与命中动画，对方座位累计被砸次数；纯娱乐，**不进战斗日志、不改血量、不影响判定**，同一玩家 2.2 秒冷却
- **对局回放**：顶栏「🎬 回放」打开播放器，左侧列出本房间最近 5 局（含「● 进行中」实时局），中间逐帧还原座位/血量/出拳揭示/行动顺序/日志，底部支持首帧/上一帧/播放暂停/下一帧/进度条拖拽/0.5–4× 倍速，可一键导出 JSON
- **屏幕适配**：手机横放（≤560px 高）自动切换紧凑牌桌——座位条压缩、中央分栏、手牌横向可滑、日志与发言改为可收起抽屉；手机竖屏隐藏侧栏并把牌桌改为内部滚动，保证「开始出拳」按钮始终一屏可见；桌面端整桌单屏不滚动
- **房间管理**：房主可解散房间（全员退出）；玩家可随时退出房间（对局中退出=淘汰出局）；胜负判定为全屏弹层（胜者卡面+再来一局）；昵称必填且本设备记忆

- **单人开局**：填昵称 + AI 数量 → 直接开局
- **创建房间**：获得 4 位邀请码 → 朋友在「加入房间」输入码加入 → 房主开始游戏
- **单设备多人**：「本机玩家数」选 2 以上 → 出拳阶段按提示传递设备，每人亲自出拳（提交后不回显拳种）
- **机制测试场**：首页入口，运行全部测试用例（PASS/FAIL、种子复现、完整结算日志）

## AI 难度

房主在大厅卡位区选择，整局统一生效。AI 与真人走**完全相同的引擎接口**（`submitThrow` / `submitAction`），不存在偷看隐藏出拳或直接改状态的作弊路径——难度差异只体现在「出拳策略」与「行动优先级」上。

| 难度 | 出拳策略 | 行动策略 |
|---|---|---|
| 🤖 休闲 | 纯随机 | 能打就打，否则随机移动；不会用技能组合 |
| 🤖 普通 | 上一轮对手的出拳做简单反制（出能赢它的拳），掺随机 | 优先击杀残血目标、残血自己优先回复、远程角色优先异房间目标 |
| 🤖 硬核 | 统计全场**已结算**出拳的频率分布，出最可能反制的手势（30% 概率扰动，避免被读死） | 威胁值排序（血量/攻击力/是否可秒）选目标，优先补刀收人头，技能与站位都按收益最大化 |

关键约束：AI 只在 `roundEnd` 之后、或自己出手时读取**已经结算并公开**的判定历史，因此难度提升不破坏隐藏出拳的公平性。所有随机数取自 `shared/src/rng.ts` 的座位随机流，固定种子下 AI 行为完全可复现（回放/测试同源）。

## 局外功能对规则的影响

战绩、丢番茄互动、回放均为**只读观察层**，不进入判定：

- 战绩字段由引擎在结算时累计（`PlayerStats`），只做展示，不参与任何伤害/胜负计算
- 互动事件只走广播通道，不写 `game.logs`、不改 hp、不占行动次数
- 回放是「状态帧录制」——服务端在状态签名变化时记一帧（每局上限 1500 帧、每房间保留最近 5 局），播放端只渲染帧，不回放隐藏出拳（`reveal` 字段始终来自已结算记录）

## 游戏流程

1. **初次判定（隐藏出拳）**：所有存活玩家同时出拳；服务端统一揭示判定。平局/三人循环全员重判，胜者（可多名）获得行动资格。
2. **二次判定（行动排序）**：资格者判定排序，输者优先行动；不剥夺资格。
3. **行动阶段**：按队列依次执行一次行动 —— 移动（到任意玩家初始房间）/ 攻击（默认同房间近战1伤）/ 回复（回满血）+ 角色技能；躲藏/找出来为可选基础行动。
4. **回合末**：延迟事件结算（如大伊万爆炸，动态判定房间成员）；每回合输出「回合小结」重点摘要。
5. HP 归零立即淘汰；最后一名存活玩家获胜。

## 角色（9 首轮验证 + 老大爷 + 默认）

| 角色 | 机制摘要 |
|---|---|
| 拔棍 | 需先「拔棍」才能造成伤害；攻击无视躲避（含隐身/躲藏） |
| 吹箫哥 | 仅能远程（异房间），无需瞄准直接攻击；无法近战 |
| 五条悟 | **2条命**（首次致死满血复活）；近3/远2（远需瞄准）；领域展开后远程免瞄准、平局算胜；领域对冲 |
| 老大爷 | 近3远2；领域展开后平局算胜、强化后近5远3；与五条悟对冲 |
| 马保国 | 混元形意太极（受伤判定反弹原伤）；闪电五连鞭；不讲武德（死后5局赢3带走对面） |
| 伍六七 | 3段AOE：每段对攻击时所在房间所有玩家1伤，段独立结算 |
| 卖大伊万的小女孩 | 向任意房间投掷大伊万，回合末爆炸毁灭爆炸时房间内全部玩家（动态判定成员） |
| 今日勇者 | 技能「抽取今日运势」（仅第一回合可用，每局限一次）：掷0-9——0/1暴毙；2/3→血1攻1；4/5→血3攻1；6→血4攻2；7→血5攻3；8→血6攻4；9→血6攻6 |
| 大贱客 | 被动吸引全场非精神伤害（仅转移伤害不转移效果）；辱骂同一人3次致死；辱骂无视躲避 |
| 大屁孩 | 判定历史连续三不同（赢平输）→暴走精神攻击；三连相同→自爆；跨回合记忆 |
| 无业游民 | 默认角色，无被动 |

角色原始数据来自附件《拔典1/2_角色速查表》（OCR 整理版），存疑处已在 `docs/GAME_RULES.md` 标注规则假设。完整原始数据见 `docs/角色速查表-原始数据.md`。
